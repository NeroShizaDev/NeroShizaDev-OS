=== НОВЫЕ МОДУЛИ (3 файла, 672 строки) ===

[+] src/menger.rs (274 строки) — Губка Менгера 3D
    - Ray marching по Distance Estimator (DE) с 3 итерациями fold
    - Нормали через градиент DE (6 вызовов, EPS=4, конечные разности)
    - Lambertian шейдинг: ambient + diffuse (dot product normal * light)
    - Фиксированная точка ×1024 (FP) — без float, без SSE
    - isqrt Newton для нормализации, 10-символьная ASCII палитра
    - 3-цветная схема: 0x06 (бронза тень), 0x0E (жёлтый), 0x0F (белый блик)
    - Камера (0, 0, -2.5*FP), наклон 260, MARCH_STEPS=48
    - Анимация: двойная ротация (вокруг Y + X), Enter для выхода

[+] src/beeper.rs (106 строк) — PC Speaker бипер
    - 16-нотная гексатоническая шкала HEX_SCALE[16]
    - PIT 8253 Channel 2: порты 0x42/0x43/0x61
    - beep(freq, ms), no_sound(), demo_hex_scale()
    - Громкость через PIT (прямоугольная волна)

[+] src/chronos.rs (292 строки) — Тройное время + тригонометрические часы
    - UTC, московское (UTC+3), двоичное время
    - Тригонометрические часы: sin/cos текущего угла
    - Классификация радикалов: 0, 1/2, √2/2, √3/2, 1
    - CMOS RTC: порты 0x70/0x71, BCD→decimal
    - x87 FPU: inline asm (fsin, fcos) — 2 вызова на кадр
    - Таблица: sin/cos = значение [радикал]

    Управление клавишами:
    - ALT_HELD: bool — отслеживание Alt (0x38/0xB8) для Alt+Fn
    - CTRL_HELD: bool — отслеживание Ctrl (0x1D/0x9D) для Ctrl+C/V/X/A
    - SHIFT_HELD: bool — отслеживание Shift (0x2A/0xAA/0x36/0xB6) для выделения

    Курсор и навигация:
    - CURSOR: usize — позиция в буфере (не INDEX; INDEX = длина)
    - set_vga_cursor(row, col) — аппаратный мигающий курсор (порты 0x3D4/0x3D5)
    - redraw_input() — прямая отрисовка в VGA (0xB8000), строка 24
    - Стрелки ←/→ — перемещение курсора
    - Home/End — прыжок в начало/конец строки
    - Delete — удаление символа под курсором
    - Вставка в середину: сдвиг BUFFER[CURSOR..INDEX] вправо
    - Backspace: сдвиг BUFFER[CURSOR..INDEX] влево

    Выделение текста:
    - SEL_ACTIVE, SEL_START, SEL_END — диапазон выделения
    - Shift+←/→ — посимвольное выделение
    - Shift+Home/End — выделение до края
    - Подсветка: Black on Yellow (0xE0) — инверсия Yellow on Black
    - Backspace/Delete при выделении — удаляет блок

    Буфер обмена:
    - CLIPBOARD: [u32; 64], CLIP_LEN — независимый буфер
    - Ctrl+C — копировать выделение (или весь буфер)
    - Ctrl+V — вставить на позицию курсора (заменяет выделение)
    - Ctrl+X — вырезать выделение
    - Ctrl+A — выделить всё
    - do_copy(), do_paste(), do_cut(), do_select_all(), delete_selection()

    Хоткеи F1-F12:
    - HOTKEYS: [[u32; 64]; 12] — 12 слотов × 64 кодпоинта (3072 байта)
    - HOTKEY_LEN: [usize; 12], RECORDING_SLOT: Option<usize>
    - Alt+Fn — начать запись → набрать команду → Alt+Fn — сохранить
    - Fn — выполнить сохранённую команду (загрузка в BUFFER → Enter)
    - handle_fkey(slot) — единая логика записи/выполнения

    История команд:
    - HISTORY: [[u32; 64]; 32] — кольцевой буфер на 32 команды
    - HIST_LEN, HIST_COUNT, HIST_IDX, HIST_NAV — навигация
    - HIST_SAVE — сохранение текущего ввода при навигации
    - ↑ (ArrowUp) — предыдущая команда
    - ↓ (ArrowDown) — следующая / возврат к текущему вводу
    - push_history() — сохранение при Enter
    - history_up(), history_down() — навигация с восстановлением

    Статистика использования:
    - CMD_STATS: [u32; 9] — счётчик по каждой команде
    - CMD_TOTAL: u32 — общий счётчик
    - Индексы: 0=Exit 1=Help 2=Clear 3=Status 4=Reboot 5=Menger 6=Beep 7=Time 8=Unknown
    - Показывается в команде 'статус' / 'status'

    Скроллбэк (прокрутка):
    - SCROLL_MODE: bool, SCROLL_OFFSET: usize
    - PageUp — вход в режим прокрутки
    - PageDown — листать вниз / выход из скролла
    - Enter/Esc/любая клавиша — выход из режима
    - enter_scroll_mode(), scroll_page_up(), scroll_page_down(), exit_scroll_mode()

    Клавиатура/раскладка:
    - CapsLock — медленный Enter (подтверждение Da/Otmena)
    - ScrollLock — переключение RUS/ENG (индикатор в VGA row 0, col 77)
    - PauseBreak — отмена подтверждения
    - Escape — сброс буфера, отмена подтверждения
    - qwerty_to_russian(c) — полная QWERTY→ЙЦУКЕН карта (67 символов)
